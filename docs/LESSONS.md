# Evidence-backed lessons

- 2026-09-11: Historical transcript includes obsolete stack decisions and tool output; use final decisions and active feature specs as authority.
- 2026-09-11: Refresh replay detection must revoke through a committed conditional update; throwing from the same transaction rolls back the revocation. Access JWTs must carry a session ID and the guard must verify it remains active.
- 2026-09-11: PostgreSQL unique constraints allow multiple null values. Generic RSVP updates therefore use a transaction-scoped advisory lock rather than nullable composite upsert.
- 2026-09-15: Jawaban server yang hanya menggemakan permintaan tidak boleh ditugaskan kembali ke state lokal. Itu bukan sinkronisasi melainkan penimpaan, dan kalau state itu diawasi watcher, penugasannya memicu watcher yang sama — penjaga berbasis flag gagal karena flag-nya sudah direset sebelum antrean watcher Vue di-flush. Terukur: satu suntingan jadi 13 revisi dalam 12 detik, lalu berulang selamanya.
- 2026-09-15: `canvas.toBlob(blob => …, 'image/webp')` boleh mengembalikan PNG; spesifikasinya mengizinkan browser mengabaikan jenis yang diminta. Nama berkas dan MIME wajib dibaca dari `blob.type`, bukan dari yang diminta — kalau tidak, pemeriksaan magic-byte di server menolak setiap unggahan dari browser tanpa encoder yang bersangkutan.
- 2026-09-15: `document.fonts.ready` tidak dapat dipercaya sebagai penantian dalam tes. Satu `FontFace` ber-status `error` membekukan `FontFaceSet.status` di `loading` selamanya di WebKit, dan deklarasi `@font-face` ganda (subset + rentang penuh) membuat itu mudah terjadi. Penantian tanpa batas di dalam tes menyamar sebagai kegagalan langkah lain, karena yang dilaporkan adalah langkah yang kebetulan berjalan saat tenggatnya lewat — baca trace, jangan percaya pesan gagalnya.
- 2026-09-16: Nilai yang menentukan apakah container bisa dihubungi tidak boleh hidup hanya di berkas env yang tidak terlacak git. `HOST=0.0.0.0` ditulis tangan sekali ke `api.env` di server; siapa pun yang menyusun ulang berkas itu mendapat bawaan `127.0.0.1`, yang di dalam container berarti loopback container itu sendiri — proxy di container lain menjawab 502 sementara log API tetap bersih. Tempatnya di `environment:` compose, yang menang atas `env_file:`.
- 2026-09-16: Path media relatif (`MEDIA_LOCAL_DIR=./.data/media`) diselesaikan terhadap cwd proses, dan `pnpm --filter <paket> start` menjalankan proses dari direktori paket, bukan akar repo. Volume yang dipasang di `/app/.data/media` karena itu tidak pernah menerima satu berkas pun — API menulis ke `/app/apps/api/.data/media`, di lapisan container yang dibuang tiap rilis. Gejalanya identik dengan tidak memasang volume sama sekali: nol galat, foto hilang. Path mount dan path tulis harus diperiksa sebagai satu pasangan, bukan masing-masing.
- 2026-09-16: Log boot yang menuliskan alamat sebagai literal (`http://127.0.0.1:${port}`) alih-alih alamat yang benar-benar di-bind membuat kegagalan jaringan terlihat sehat. Cetak nilai yang dipakai, bukan nilai yang diasumsikan.
