# aruna-feature-artifacts

Read docs/README.md and the feature README, SPEC, PLAN and latest CHANGELOG. Preserve existing decisions; latest explicit user revision wins. Keep docs gitignored. Each feature uses README, SPEC with requirement IDs and FE/BE/permission acceptance, PLAN with ordered files and checks, UI-BRIDGE, sources/INDEX, revisions and verification. Archive superseded decisions before changes, append dated changelog entries, record actual command outcomes and unresolved environment dependencies. Never copy secrets into docs. Distinguish downloaded references, production licensed assets and verified browser evidence. Update status before handoff.
