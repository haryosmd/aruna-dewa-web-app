# Cultural and visual curation

Start with place/culture, desired mood, palette, material, and intended composition. Inspect `originals/*/catalog.json` before generating more assets. Use `recommend.mjs --catalog <file> --theme <tag> --style <tag>` for an explainable shortlist. It filters theme and usage, ranks matching style/cultural anchors and selects one per category; it is a deterministic assistant to visual judgment, not a trained cultural classifier.

For gaps, research official cultural institutions, museums, academic work or recognized community sources. Keep the source URL, checked date, supported claim and uncertainty. Distinguish an architectural/instrument identity from a common material and decorative flora. Avoid mixing regional roof forms or labeling a generic botanical detail as a sacred motif. If a motif has ceremonial restrictions, record the source-specific context before choosing it.

Compose a set around one strong cultural anchor and a coherent family of companion pieces:

- Architecture/venue and instrument/symbol identify the theme.
- Frame, divider, corners, material motif and edge layers organize the page.
- Flora supports the palette and mood; it need not be culturally exclusive.
- Match illustration medium, silhouette density, optical scale, value contrast and lighting. SVG and watercolor can coexist when placement clearly separates architectural anchors from botanical framing.

The first Sunda pack uses a stylized Julang Ngapak roof, angklung and an original bamboo-weave interpretation. Jasmine, bamboo leaves and fern are companion garden imagery, not exclusive symbols. References live in its `CULTURE.md`. The package is a contemporary interpretation, not an architectural reconstruction.

For new themes, use equivalent research instead of recoloring this pack. Record why each selection fits, which categories are missing, and what must be created. No vector database, persistent external service, or automatic background learning is required: catalogs and sourced notes provide the reusable memory.
