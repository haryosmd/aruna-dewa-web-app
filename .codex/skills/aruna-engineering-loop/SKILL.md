# aruna-engineering-loop

Read the feature artifacts. Define observable acceptance, inspect current code, write meaningful failing regression tests for business behavior, implement the smallest cohesive change, then run targeted checks and review. Record dependencies in docs/DEPENDENCIES.md and progress in docs/EXECUTION.md. Delegate only bounded independent ownership; never revert others. Browser never decides permissions or prices; validate membership, entitlements and published snapshots on server. Keep secrets server-side. Record demonstrated failures and their fixes in docs/LESSONS.md; no autonomous background self-modification. This is a project workflow inspired by engineering loops, not a claimed official Karpathy framework.
